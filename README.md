# ECHO RUN v5 · 地狱突围（回声猎手）

> 纯静态霓虹俯视生存游戏。单文件、无依赖、无后端，打开网页就能玩——设计目标就是「在地铁上也能单手玩一局」。

**在线游玩：** https://azdezhishijiangtang.github.io/echo-run/

> **没有账号、没有排行榜服务器、没有埋点、不收集任何数据。** 分数记录只保存在你自己的浏览器里；页面不向任何外部地址发请求。

## 玩法目标

在俯视竞技场里操控角色躲避越来越密的弹幕，靠**走位**与**冲刺**活下去，同时靠近晶体获取经验、升级变强。

- **冲刺穿过子弹 = 极限闪避**：冲刺带无敌帧，穿过弹幕能立刻缩短冲刺冷却并加分，是活下去的关键。
- 每波 **18 秒**，敌人更多更快；击破**精英回 8 点**、**BOSS 回 20 点**生命。
- **每 5 波精英、每 10 波 BOSS**；第 4 波起出现蜂群、重装、狙击、分裂波，第 6 波起猎人入场。
- 升级时**战场暂停 · 三选一**（可按数字键 `1` / `2` / `3` 选择）。
- v5 为「地狱难度」：预警更快、弹幕更密，靠走位与冲刺硬闯。

## 操作方式

| 设备 | 移动 | 冲刺 | 暂停 | 升级选择 |
|---|---|---|---|---|
| **桌面** | `WASD` / 方向键 | `空格`（带无敌帧） | `P` / `Esc` | 数字键 `1` / `2` / `3`，或鼠标点选 |
| **手机 / 平板** | 左侧虚拟摇杆 | 右侧冲刺按钮 | 顶部暂停按钮 | 直接点选卡片 |

其他细节：

- 切到别的标签页 / 窗口失焦会**自动暂停**（「战场已暂停，喘口气再回来」），回来后手动继续。
- 摇杆使用 Pointer Events + pointer capture；强制暂停或结束时**会正确释放指针捕获**并把摇杆归位，不会「粘住」。
- 支持 `prefers-reduced-motion`（减少动画），并适配移动端安全区域（刘海屏）。

## 波次与系统

| HUD 元素 | 含义 |
|---|---|
| `WAVE 01` | 当前波次 |
| 计时 `00:00` | 本局存活时间 |
| 分数 | 当前得分（冲刺闪避、击破敌人等会加分） |
| 生命条 | 当前生命 / 上限 |
| XP / LV | 经验与等级，靠近晶体获取经验 |

- **升级三选一**：每次升级弹出三张卡片，选择后继续战场。
- **本机排行榜**：结算后记录到本机，主菜单可查看；数据不做任何上传或跨设备同步。
- **关于 / 支持 / 玩法共建**：主菜单内有独立面板，含作者信息、打赏方式与「你想玩到什么」的共建说明。

## 两种模式

| 模式 | 说明 |
|---|---|
| **自由生存** | 每局用当前时间 + 随机数生成种子，随开随玩 |
| **地狱每日** | 按 UTC 日期生成**固定种子**，当天所有人面对同一套波次与随机序列，适合挑战同一局的分数 |

每日模式在主菜单会显示当天日期（UTC）。两种模式都可随时「重新开始本模式」。

## 数据与隐私

| 数据 | 存在哪里 | 会不会离开设备 |
|---|---|---|
| 本机分数记录（排行榜） | 当前浏览器 `localStorage` | **不会** |
| 当前局状态（波次、生命、分数等） | 只在运行内存里 | **不会** |
| 站点自身 | 无后端、无账号、无统计、无外部请求 | —— |

- 排行榜读取时做了**类型过滤**，并用 `textContent` 渲染，全站不使用 `innerHTML`，不受恶意本地数据注入影响。
- 清理浏览器数据会清掉本机排行榜，且**无法找回或跨设备同步**。
- 页面所有资源（含图片）都来自本站目录，不依赖任何 CDN。

## 浏览器与设备兼容性

- 单文件原生 JS，无框架、无构建、无第三方依赖。
- 桌面与移动端共用一套输入层：键盘 / Pointer Events / 触屏摇杆，支持 `touch-action: none` 防止页面滚动干扰。
- 适配不同 DPR 与窗口尺寸，横竖屏均可；`resize` 时重算画布。
- 尊重系统「减少动态效果」偏好。
- 需要浏览器支持 Canvas 2D 与 `requestAnimationFrame`（现代浏览器均支持）。

## 本地运行与部署

本项目**没有构建步骤**，`index.html` 就是完整游戏：

```bash
# 任意静态服务器即可，例如
python3 -m http.server 8000
# 然后打开 http://localhost:8000/
```

> 直接双击打开 `index.html`（`file://`）通常也能运行；若遇到浏览器对本地文件的限制，用上面的静态服务器即可。

**部署**：推送到 `main` 后由 GitHub Actions 把静态文件发布到 Pages；也可直接把整个目录放到任意静态托管。

部署注意：

- 请保留 `images/` 目录（关于面板与打赏图片）；删除会导致图片 404。
- 页面已内联 favicon（`data:,`），避免浏览器自动请求 `/favicon.ico` 产生 404。
- 页面设置了 `Referrer-Policy: no-referrer`。

## 已知限制

- **排行榜是纯本机的**：不同设备、不同浏览器之间不共享，清理浏览器数据后会消失。
- 游戏为单文件架构，内联脚本未启用严格 CSP；由于全站不使用 `innerHTML`、不加载外部脚本、不处理用户可控 HTML，注入面已通过代码与运行时验证予以排除。若后续引入外部脚本或动态 HTML，需重新评估并加 CSP。
- 每日模式按 **UTC 日期**切换，与中国本地时间的自然日不完全一致。
- 高刷屏与低端设备的手感会有差异；帧率极低时可尝试关闭后台标签页。
